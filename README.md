# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shopping application.

## Project Description

The application allows users to browse houseplants organized into different categories, add plants to a shopping cart, adjust quantities, remove items, and view the total cost of their cart.

## Features

- Paradise Nursery landing page
- About Us section
- Plant categories
- Multiple houseplants in each category
- Plant thumbnails, names, and prices
- Add to Cart functionality
- Dynamic cart item count
- Redux state management
- Increase and decrease cart quantities
- Delete items from cart
- Total cart amount calculation
- Checkout button with Coming Soon message
- Continue Shopping functionality
- Navigation between Home, Plants, and Cart

## Technologies Used

React, Vite, Redux Toolkit, React Redux, React Router DOM, JavaScript, CSS

## Project Structure

- `src/App.jsx` - Application routes and landing page
- `src/App.css` - Application styling and landing page background
- `src/components/AboutUs.jsx` - About Us section
- `src/components/Navbar.jsx` - Navigation bar
- `src/components/ProductList.jsx` - Plant listing
- `src/components/CartItem.jsx` - Shopping cart
- `src/redux/CartSlice.jsx` - Redux shopping cart slice
- `src/redux/store.js` - Redux store
- `src/data/plants.js` - Plant product data
